Configure IMAP + SMTP in ccc.toml

Add a [plugin.mail] section to ccc.toml (store the password in an environment variable for safety):

[plugin.mail]
imap_host = "imap.ionos.com"
imap_port = 993
smtp_host = "smtp.ionos.com"
smtp_port = 587
username = "you@yourdomain.com"
password_env = "NUNTIUS_MAIL_PASSWORD"
from_name = "Lucerna Media"
from_address = "you@yourdomain.com"

Works with IONOS Mail, Fastmail, Gmail (App Password), or any standard IMAP/SMTP provider.
