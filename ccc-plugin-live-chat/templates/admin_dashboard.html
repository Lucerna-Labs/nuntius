Master switch

When disabled, the WebSocket endpoint returns 503 and the recent-history endpoint is empty. Existing connections are closed on the next message round-trip.

Rate limits

Defends the room against spam and noisy clients. None of these limits are per-IP; they're per WebSocket connection.

History

How many recent messages to keep in memory and expose via /api/live-chat/recent. Older messages fall off the end of the ring.

Ban list

Banned nicks (case-insensitive, comma- or whitespace-separated) have their messages silently dropped. The server still sends them the broadcast — they just can't contribute.

Settings apply to new messages immediately; existing connections keep the values they were opened with.

How clients connect

Browser snippet for the public listen page's chat sidebar:

const ws = new WebSocket("ws://your-host/api/live-chat/ws");
ws.onmessage = (ev) => {
  const f = JSON.parse(ev.data);
  if (f.type === "hello")   renderHistory(f.history);
  if (f.type === "msg")     appendMessage(f);
  if (f.type === "rejected") toast(f.reason);
};
ws.onopen = () => ws.send(JSON.stringify({type:"msg", nick:myNick, text:myInput.value}));
