How this works

The watcher pings the engine every {{ tick_seconds }}s. It opens a side-listener against the mount, counts bytes, and reads /api/radio/nowplaying for the current track.

States: healthy (all signals good), degraded (one signal weak), down (multiple signals bad).

Discord / generic webhook URLs fire on each state change, gated by the cooldown so you don't get spammed.
